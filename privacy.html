1. Who we are

Shorts Agent (“the tool”) is a private desktop application operated by {{NAME}} ({{EMAIL}}), the owner of the YouTube channel “GTA VI Streams”. The tool is used only by its operator and only for that channel.

2. Use of YouTube API Services

Shorts Agent uses YouTube API Services. By using the tool you are also bound by the YouTube Terms of Service, and Google’s handling of data is described in the Google Privacy Policy (http://www.google.com/policies/privacy).

3. What data the tool accesses

After the channel owner signs in with Google (OAuth 2.0) and grants permission, the tool accesses only the owner’s own channel:

  • channel ID and title, the list of the channel’s uploads and live broadcasts and their status;
  • metadata of the owner’s own videos (title, description, duration, processing status);
  • the owner’s own stream recordings, to cut highlight clips and choose a thumbnail frame;
  • the owner’s own playlists, to add episodes to a series playlist.

The tool does not access other users’ data, comments, subscribers’ personal information, analytics, or any data from channels the operator does not own.

4. How the data is used

  • to detect when a stream has ended and which recording to process;
  • to create and upload YouTube Shorts made from the owner’s own streams;
  • to update the title, description (including chapters), tags and thumbnail of the owner’s own recordings;
  • to add those recordings to a playlist on the owner’s channel.

To pick the best moments and write titles, short preview clips or still frames of the owner’s own streams may be sent to the Google Gemini API for analysis. No YouTube account credentials, OAuth tokens or data about other people are sent there.

5. Storage and retention

  • The OAuth token and all working files are stored locally on the operator’s computer only. There is no server or cloud database.
  • The tool keeps a local processing log with the IDs and titles of the owner’s own videos. Data obtained from YouTube API Services is refreshed or deleted within 30 days, as required by the YouTube API Services Developer Policies.
  • Temporary video files are deleted automatically after processing.

6. Sharing

No data is sold, rented or shared with third parties, except the analysis requests to Google Gemini described in section 4.

7. Cookies

This website and the tool do not use cookies or tracking. The site is hosted on GitHub Pages; see GitHub’s privacy statement for server logs.

8. Revoking access and deleting data

  • Access granted to the tool can be revoked at any time on the Google security settings page: https://security.google.com/settings/security/permissions.
  • After revocation the tool can no longer access the channel. To request deletion of any locally stored data, contact {{EMAIL}}; it will be deleted within 7 days.
